## Placement targets

- **`linux-namespace-desktop`**: Runs on the Linux namespace desktops: LibreOffice only, and the evaluator grades captured files (or a constant rule), so the host can grade from the bytes the desktop leaves behind.
- **`linux-needs-other-app`**: OSWorld (Ubuntu) task, but it needs an app the namespace desktop does not ship (it registers LibreOffice only). Runs on Linux once that app is added to the desktop image; never needs Windows.
- **`linux-needs-guest-probe`**: OSWorld (Ubuntu) task whose evaluator reads live guest state (for example the accessibility tree or a command's output), not a saved file. Needs a guest probe on the desktop before it can be graded.
- **`windows-vm`**: WindowsAgentArena task: built for WAA's Windows 11 image (Windows paths, Windows apps, WAA's in-guest server). Needs the Windows VM.

## Reason and requirement codes

- `LIBREOFFICE_ONLY_FILE_GRADED`: Only LibreOffice apps, and every evaluator getter is file-based.
- `INFEASIBLE_TASK_GRADED_ON_AGENT_FAIL_ACTION`: Upstream `infeasible` task: the evaluator passes only if the agent's last action is FAIL. An agent that says done here is a false done by construction.
- `WAA_WINDOWS_IMAGE`: Part of WindowsAgentArena, whose tasks assume WAA's Windows 11 image.
- `WINDOWS_PATHS`: The task's config or evaluator names Windows paths (C:\...).
- `WINDOWS_ONLY_APP`: Notepad or File Explorer: Windows-only apps.
- `APP_NOT_ON_DESKTOP:<app>`: Needs this app on the desktop; the namespace desktop has none but LibreOffice.
- `GUEST_PROBE_GETTER:<getter>`: This upstream getter reads live guest state, not a captured file.
- `SEED_ASSETS_LICENSE_UNCLEAR`: Needs: the task downloads seed files whose license is unclear; they are not fetched until a lead ruling (README §1).
- `POSTCONFIG_EXECUTOR`: Needs: the upstream evaluator runs postconfig steps (activate a window, press Ctrl+S, sleep) before grading; the harness must execute them in the desktop.
- `NETWORK_PROXY`: Needs: the task sets `proxy: true` (network); namespace desktops have networking off by default.
