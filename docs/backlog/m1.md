### M1-019 (TIF-48) Always-cleanup on the failure path + guest-health precondition
- **status:** pending
- **owner:** build
- **blocked_by:** none
- **description:** A trial cleans up only on success, so a failed trial leaks `soffice` processes and run directories; a later trial can then read a foreign document and produce a misleading refutation (or, worse, a misleading pass). Found in log 27. Two parts: (a) ALWAYS cleanup on every exit path — kill `soffice`, remove the trial's guest run dir and temp profile, even when the trial throws; (b) a guest-health precondition evaluated before a trial starts: no stray `soffice` processes and no leftover run dirs beyond the current one, otherwise abort `uncertain` with a `guest-contaminated` guard failure rather than risk a contaminated reading.
- **acceptance:** a forced-failure trial leaves zero stray soffice processes and no leftover dirs; a trial started against a deliberately contaminated guest aborts `uncertain` with the guest-contaminated predicate (never verified, never refuted); tests cover both; verified on the VM.

### M1-024 (TIF-55) Verifier: negative assertions (`preserveCells`) borrowed from OSWorld-Verified
- **status:** pending — design at docs/baseline/screenshot-agent.md §1c.1
- **owner:** build
- **blocked_by:** M1-007 (done)
- **description:** M1's verifier asserts one cell and says nothing about the other rows, so an agent that "fixes" the answer by rewriting untouched regions is not caught. OSWorld-Verified added `preserve_cells` for exactly this. Add a `preserveCells(region)` predicate to the declarative predicate language and have `UnoVerifier` check it against the persisted file it already parses. Applies to both arms, and it closes a real false-success path in the Myco path too.
- **acceptance:** a trial that sets the target cell correctly **and** alters a cell outside the target region is `refuted` with a `preserve-cells` reason; a clean trial is unaffected; the predicate cannot be satisfied by the agent's claims alone; tests cover both directions; **plus a mutation self-test on the verifier itself** — hand-written edits to a correct run (an unrequested text or reference field filled; target value omitted; target value wrong) each confirmed against the end state, per WorkArena's audit method (arXiv 2610.09142), where 36/36 unrequested-field mutations passed their verifier and 0 planted omissions did.
